## AI-HardSI 3.0
去年 (2024) 由于备考硕士研究生以及今年的大学本科毕业相关事宜, 插件编写几乎停滞, 且部分 issue 未处理, 在此表示歉意, 劳请各位理解, 目前已经研一, 现陆续恢复插件更新及 issue 处理😽
> Due to the preparations for the Post Graduation Entrance Exam last year and this year's university graduation, my plugin development almost came to a standstill, and some issues were not addressed. I apologize for this and ask for your understanding. Currently, i am now a freshment postgraduate student, and I am gradually resuming plugin updates and issue processing.

Ai-HardSI 3.0 版本目前处于开发 (dev) 分支, 目前思路为各个子特感插件不再设置强制目标选择, 将由一个目标分配插件控制目标选择及特感协同, 若无需目标选择插件可直接编译任意特感子插件使用, 目前插件及功能并不完善, 接受大家意见并陆续更新, 欢迎向我提出 AiSI 增强建议或提交代码🤗
> The AI-HardSI 3.0 version is currently in the dev branch, and my idea is no longer force to distribute survivor target to each type of SI, instead, a target distribution plugin will be used to distribute target to SI and for SI collaboration. If you don't need this target distribution plugin, you can compile any SI plugin and use it. Currently, the plugin and functions are not complete, and updates are accepted from everyone. Welcome to give me suggestions and update some code for my AiSI enhancement.
